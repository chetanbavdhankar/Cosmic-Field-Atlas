# Claim audit: native halo milestone and residual diagnostic

This is an internal evidence/scope review, not external peer review.

| Claim | Evidence | Permitted interpretation |
|---|---|---|
| Original halo source transfer is intact | Producer MD5 plus independent complete-file MD5/SHA256 replay | Exact advertised file integrity; not validation of its physical model |
| Required native halo rows satisfy this admission contract | All 33,585,418 rows checked before eligibility; exact-ID uniqueness and source replay | Required columns only; not calibration of every optional physical property |
| Fixed source split is reproducible | All-eligible hash ranking and 65,536 row/ID replays | Same correlated source volume, not independent cosmic-variance samples |
| Four velocity fits are numerically qualified | Rank, normal equations, independent complex predictions, held scoring after all fit checks | Representation fit correctness, not a density or observation likelihood |
| Primary held vector RMS improves from 530.063 to 438.441 km/s | Corrected v3 summary and independent scalar replay | Descriptive host-number-weighted improvement in this volume |
| Much halo motion remains unresolved | Saved held residuals and plotted distributions at all four fixed cutoffs | Cannot isolate vorticity, nonlinear motion, tracer physics or truncation from this test |
| Primary residuals show nearby coherence and heavier sample tails | Frozen posthoc million-pair/moment diagnostic and independent replay | Development diagnostic; first bin only 37 pairs; no population intervals or normality test |
| Existing observations need robust discrepancy treatment | General modelling implication of retained mismatch evidence | No object is newly classified as a bad measurement or removed; no adopted empirical noise law |
| A matter-density reference may be feasible | Public particle file listing and first header/layout/source review | Feasibility only; header inconsistency remains, no particle density admitted |

Rejected interpretations: all-sky observational validation, cluster-scale velocity recovery, full matter-density truth from halo virial masses, a Milky Way/Galactic coordinate assignment, evolution from a single epoch, independent-volume calibration, guaranteed uncertainty coverage, or proof that the observed selection mismatch has been fixed. All seven empirical gates remain false and no product has been promoted to the field viewer.

The v1 epoch assumption and v2 constant-baseline correlation reporting failure are retained with explicit amendments. Corrected reporting did not change the source split or fitted fields. The residual figure's layout correction changes presentation only. These corrections must remain visible in any later research paper.
